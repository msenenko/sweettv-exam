## Protocol

- View log: `dataset11-30.csv`. Dropped 17 exact duplicate view rows (5,821,987 -> 5,821,970).
- Each schedule file was restricted to its own ISO weeks before joining.
- `tv_show_id = 0` airtime is not an item and was dropped from the join.
- Join keys: `vsetv_id = channel_id`; overlap = `min(view_stop, programme_end) - max(view_start, programme_start) > 0`.
- Programme end = schedule `start_time + duration` seconds.
- Overlap was summed over all view rows of the same user on the same airing (airing = channel + programme start); `frac = min(1, summed_overlap / duration)`.
- No model was fit.
